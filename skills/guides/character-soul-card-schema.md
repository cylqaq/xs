# 灵魂卡字段契约（Character Soul Card Schema）

> **模板**：`stories/_template/canon/characters/char-protagonist.example.md`  
> **实例**：每本书 `canon/characters/{id}.md`  
> **联动**：`voice-matrix.yaml`、`persona-shifts.yaml`、`power-defects.yaml`

## 必填节（character-forge）

| 节 | 用途 |
|----|------|
| 标识 | id、姓名、称呼、角色位 |
| 年龄与学龄轨迹 | 关键年表节点 |
| 外貌锚点 | 不可漂移视觉特征 |
| 日常习惯 | 写作贴身感 |
| 应激反应与微表情 | 虐/冲突场景 |
| 真灵与能力 | 引用 rules；**缺陷行为模式** |
| 欲望 / 恐惧 / 秘密 | 三件套 |
| 家庭与社会 | 父母、阶层、学校 |
| 性格基线与暗面 | 基线 + 压力下反差 |
| 关系网详表 | 边 + 情绪方向 |
| 声线速查 | 指向 voice-matrix 条目 |
| 转变预警 | 指向 persona-shifts id |
| 写作禁忌 | 本书 OOC 补充 |

## 禁止

- 在 `_template` 写真实书名剧情（仅 example 占位）
- 灵魂卡与 voice-matrix 声线矛盾
- 无 persona-shifts 登记的大幅性格跳变
